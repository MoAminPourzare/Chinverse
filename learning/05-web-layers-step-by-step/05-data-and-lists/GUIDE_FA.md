# فاز ۵ — داده را از توصیف ظاهر جدا کن

ورودی: یک کارت با متن ثابت. خروجی: سه کارت از یک آرایه، بدون سه بار کپی‌کردن JSX.
هنوز رفتار انتخاب اضافه نشده است؛ این مرحله فقط داده، تکرار و نمایش عدد را هدف می‌گیرد.

## ترتیب نوشتن

1. src/books.js را بساز: آرایه‌ای از کتاب‌ها؛ هر عضو id، title، topic و price دارد.
2. قیمت را عدد نگه دار. در src/format-price.js یک تابع بنویس که عدد را فقط برای نمایش قالب‌بندی کند.
3. در App.jsx این دو فایل را import کن.
4. کارت ثابت را داخل books.map قرار بده؛ برای هر book یک article توصیف می‌شود.
5. متن‌های ثابت کارت را با book.title، book.topic و نتیجهٔ formatPrice جایگزین کن.
6. روی article مقدار key={book.id} بگذار؛ React برای تشخیص هویت اعضای فهرست از آن استفاده می‌کند.
7. شمارنده را از books.length نمایش بده و دو قانون book-list و count-badge را به CSS اضافه کن.

index.html و main.jsx همان فاز ۴ می‌مانند. لازم نیست در هر مرحله همه‌چیز را عوض کنی.

## چرا این ترتیب؟

ابتدا شکل داده را مشخص می‌کنیم، سپس می‌نویسیم هر عضو چطور دیده شود.
map یک ابزار JavaScript است؛ React و JSX خودشان به آرایهٔ ما داده اضافه نمی‌کنند.
formatPrice تابع معمولی JavaScript است و نه کامپوننت: عدد می‌گیرد و متن برمی‌گرداند.

## آزمایش و تمرین

پاسخ آماده: npm run dev -- 05. سه کارت و شمارندهٔ سه کتاب را باید ببینی.
یک کتاب چهارم با id یکتا به books.js اضافه کن؛ بدون دست‌زدن به JSX باید کارت و شمارنده اضافه شوند.
قیمت را تغییر بده؛ عدد در داده باقی می‌ماند ولی نمایش فارسی آن تغییر می‌کند.

## معیار پایان

بتوانی بگویی افزودن کتاب یک تغییر داده است و تغییر ساختار کارت یک تغییر JSX.
key شناسهٔ پایدار برای React است؛ قرار نیست به‌عنوان ویژگی معمول DOM روی صفحه نمایش داده شود.
قدم بعد: توصیف کارت را به یک کامپوننت مستقل با ورودی مشخص منتقل می‌کنیم.
