# فاز ۱۰ — ابزار مشاهده را روی برنامهٔ آماده سوار کن

ورودی: فروشگاه دارای انتخاب، جست‌وجو و TypeScript. خروجی: همان پروژهٔ کامل 04-web-layers.
نسخهٔ نهایی رفتارهای قبلی را نگه می‌دارد و برای دیدن پشت صحنه، Inspector و صفحهٔ DOM مستقیم اضافه می‌کند.

## ترتیب نوشتن

1. src/raw-imports.d.ts را اضافه کن؛ به TypeScript می‌گوید import با ?raw یک رشتهٔ متن برمی‌گرداند.
2. src/Inspector.tsx را بساز؛ ابتدا فقط نمایش متن سورس را اضافه کن.
3. تب خروجی تبدیل‌شده را اضافه کن. dev.mjs هنگام شروع، فایل‌های مقایسه را در generated می‌سازد.
4. تابع readDom را بنویس؛ DOM فعلی book-list را با outerHTML می‌خواند و یک snapshot متنی ذخیره می‌کند.
5. در App، Inspector را وارد کن و کنار پنل فروشگاه قرار بده؛ stateهای فروشگاه در App باقی می‌مانند.
6. متن‌های معرفی فناوری‌ها و ساختار نمایشی نهایی App را اضافه کن. این‌ها توضیح و چیدمان‌اند؛ قانون انتخاب و جست‌وجو تغییر نمی‌کند.
7. styles.css نهایی را اضافه کن؛ گرید دو ستونه و واکنش‌گرایی ابزار مشاهده در این مرحله وارد می‌شوند. min-width: 0 روی فرزندان گرید اجازه می‌دهد متن طولانی کد، کل صفحه را در موبایل عریض نکند؛ کدهای بلند داخل پنل خودشان اسکرول می‌شوند.
8. direct-dom.html و direct-dom.js را برای مقایسه اضافه کن؛ از ایدهٔ فاز ۳ استفاده می‌کنند ولی صفحهٔ جدا دارند.
9. در کارت نهایی h2 به h3 تغییر می‌کند چون پنل فروشگاه حالا h2 خودش را دارد؛ سلسله‌مراتب عنوان‌ها را رعایت می‌کنیم.

main.tsx، نوع Book، داده‌ها و قرارداد props از فاز قبل همان نقش‌ها را دارند.

## اجرای نهایی و مشاهده

پاسخ آماده: npm run dev -- 10. بررسی نوع: npm run check -- 10.
در مرورگر کتابی را انتخاب کن، تب خواندن DOM را بزن و class و aria-pressed را پیدا کن.
سورس TSX را با JavaScript تبدیل‌شده مقایسه کن: نوع‌ها حذف و JSX تبدیل شده‌اند، ولی منطق تابع مانده است.
لینک نسخهٔ بدون React را باز کن و همان تغییر متن و کلاس را در روش مستقیم ببین.

## دو نکتهٔ مهم دربارهٔ ابزار آموزش

generated فقط هنگام شروع سرور ساخته می‌شود؛ پس از تغییر سورس برای تازه‌کردنش سرور را دوباره اجرا کن.
صفحهٔ اصلی از تبدیل Vite اجرا می‌شود؛ خروجی generated فقط به شکل متن در Inspector دیده می‌شود.
نمای DOM هم زنده و خودکار نیست؛ بعد از تغییر انتخاب، دوباره خواندن DOM را بزن.
سورس و نوع‌ها عمداً در ابزار آموزش قابل مشاهده‌اند؛ حذف نوع از اجرا به معنی محرمانه‌شدن سورس نیست.

## معیار پایان

سه کتاب، انتخاب و لغو انتخاب، جست‌وجو، پیام خالی، حفظ انتخاب پنهان‌شده، تب‌ها و صفحهٔ مستقیم باید کار کنند.
با Refresh کامل انتخاب و عبارت جست‌وجو پاک می‌شوند؛ این رفتار انتظار می‌رود چون هنوز ذخیرهٔ دائمی نداریم.
تمرین پایانی: کتاب تازه‌ای با description اضافه کن و از نوع تا داده، کارت، CSS و DOM مسیر تغییر را دنبال کن.

این پایان ساخت همین مثال است. شبکه، بک‌اند، دیتابیس و Next.js مرحله‌های جداگانهٔ آموزش پروژهٔ اصلی‌اند.
