# فاز ۲ — به ساختار موجود ظاهر بده

ورودی: صفحهٔ ثابت فاز ۱. خروجی: همان محتوا، با کارت، فاصله، رنگ و عرض مناسب.
هنوز هیچ رفتار تعاملی اضافه نمی‌کنیم؛ فقط یک مسئولیت جدید داریم: ظاهر.

## ترتیب نوشتن

1. در practice پوشهٔ src را بساز و داخلش styles.css را ایجاد کن.
2. ابتدا فونت، رنگ زمینه و margin بدنه را بنویس؛ نتیجه را ببین.
3. برای page-shell عرض و فاصلهٔ بیرونی تعیین کن.
4. برای book-card زمینه، حاشیه، فاصلهٔ داخلی و گوشه‌ها را بنویس.
5. در پایان choose-button و حالت focus-visible را اضافه کن.
6. در head فایل index.html، styles.css را با link وصل کن؛ بدون این اتصال، صرف وجود CSS اثری ندارد.

ترتیب خواندن پاسخ: index.html، سپس src/styles.css. در CHANGES.diff فقط تفاوت با فاز ۱ را ببین.

## چرا کلاس داریم؟

class یک نام برای انتخاب عنصرهاست. CSS از این نام استفاده می‌کند تا ظاهر مشخصی اعمال کند.
خود نام book-card هیچ معنای پیش‌فرضی مثل سفیدشدن یا حاشیه‌دارشدن ندارد.
عرض صفحه با min و calc محدود شده تا هم در نمایشگر بزرگ خوانا باشد و هم در موبایل جا شود.

## اجرا و آزمایش

پاسخ آماده: npm run dev -- 02. تمرین خودت: npm run dev -- practice.
رنگ دکمه را عوض کن؛ سپس عرض مرورگر را کم کن. متن و رفتار ثابت‌اند، فقط ظاهر تغییر می‌کند.
با Tab روی دکمه برو و نشانهٔ فوکوس را ببین. دکمه هنوز انتخابی را ثبت نمی‌کند.

## معیار پایان

بتوانی بگویی تغییر متن در HTML انجام می‌شود و تغییر رنگ در CSS.
تمرین: مقدار padding کارت را تغییر بده و تفاوت فضای داخلی با margin صفحه را مشاهده کن.

قدم بعد: روی همین یک دکمه با JavaScript مستقیم رفتار انتخاب اضافه می‌کنیم.
