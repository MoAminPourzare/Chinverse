# کدام فایل را چه زمانی و چرا می‌نویسیم؟

این جدول برای پیدا‌کردن محل یک مسئولیت است. دستورهای دقیق نوشتن و آزمایش در GUIDE_FA.md هر فاز قرار دارند.

| اولین حضور | فایل | نیازی که آن را ایجاد می‌کند |
| --- | --- | --- |
| فاز ۱ | index.html | داشتن یک سند اولیه و محتوای قابل مشاهده |
| فاز ۲ | src/styles.css | ظاهر دادن به همان ساختار موجود |
| فاز ۳ | src/main.js | وصل‌کردن کلیک به دستور تغییر مستقیم DOM |
| فاز ۴ | src/App.jsx | توصیف نمای یک کارت با React و JSX |
| فاز ۴ | src/main.jsx | اتصال App به گرهٔ root با React DOM |
| فاز ۵ | src/books.js | نگهداری اطلاعات کتاب‌ها به شکل داده |
| فاز ۵ | src/format-price.js | تبدیل عدد قیمت به متن مناسب نمایش |
| فاز ۶ | src/BookCard.jsx | جداکردن مسئولیت نمایش یک کتاب و دریافت props |
| فاز ۷ | تغییر App و BookCard | نگهداری انتخاب در والد و اعلام کلیک از فرزند |
| فاز ۸ | تغییر App و CSS | نگهداری query و محاسبهٔ فهرست قابل مشاهده |
| فاز ۹ | src/types.ts | تعریف قرارداد مشترک Book |
| فاز ۹ | تغییر نام فایل‌ها به ts/tsx | اضافه‌کردن بررسی نوع با حفظ رفتار قبلی |
| فاز ۹ | tsconfig.json | مشخص‌کردن قوانین و محدودهٔ بررسی TypeScript |
| فاز ۱۰ | src/raw-imports.d.ts | معرفی نوع import متنی با ?raw به TypeScript |
| فاز ۱۰ | src/Inspector.tsx | نمایش سورس، خروجی تبدیل و snapshot از DOM |
| فاز ۱۰ | generated/*.js | خروجی مقایسه‌ای که ابزار اجرا هنگام شروع می‌سازد |
| فاز ۱۰ | direct-dom.html و direct-dom.js | حفظ صفحهٔ مقایسهٔ روش مستقیم در کنار نسخهٔ React |

## ترتیب نوشتن با ترتیب اجرا یکسان نیست

برای ساخت فاز ۴، اول App را می‌نویسیم، سپس فایل اتصال و بعد سند را به ورودی تازه وصل می‌کنیم.
اما مرورگر هنگام اجرا ابتدا index.html را می‌گیرد، سپس main و وابستگی‌هایش را اجرا می‌کند و App در root نمایش داده می‌شود.
برای توسعه، از مسئلهٔ همان لحظه شروع می‌کنیم؛ برای فهم اجرا، از نقطهٔ ورود دنبال می‌کنیم.

## اگر بخواهم تغییری بدهم از کجا شروع کنم؟

| درخواست تغییر | محل اصلی |
| --- | --- |
| عنوان یا قیمت یک کتاب | books.js یا در نسخهٔ نوع‌دار books.ts |
| ساختار نمایش هر کارت | BookCard.jsx یا BookCard.tsx |
| قانون انتخاب و لغو انتخاب | handleSelect در App |
| جست‌وجو در ویژگی تازه | محاسبهٔ visibleBooks در App |
| رنگ کارت انتخاب‌شده | styles.css |
| نوع ویژگی تازهٔ کتاب | types.ts، سپس داده و مصرف‌کنندهٔ آن |
| قالب نمایش عدد قیمت | format-price.js |
| نحوهٔ مشاهدهٔ سورس و DOM | Inspector.tsx |
| پورت محیط محلی | ابزار dev.mjs؛ به کد فروشگاه مربوط نیست |

بعد از اضافه‌کردن ویژگی به نوع، باید داده و نمایش آن را هم بررسی کنی؛ هیچ‌کدام خودکار جای دو بخش دیگر را پر نمی‌کند.
