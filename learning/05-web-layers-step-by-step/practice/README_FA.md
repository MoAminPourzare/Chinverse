# میز کار تو

این پوشه جایی است که خودت پروژه را مرحله‌به‌مرحله می‌نویسی.
فعلاً فقط اسکلت HTML دارد. از راهنمای ../01-html/GUIDE_FA.md شروع کن.
هر فاز کامل‌شده را داخل همین پوشه ادامه بده؛ فازهای شماره‌دار پاسخ و نقطهٔ مقایسه‌اند.

از پوشهٔ مادر npm run dev -- practice را اجرا کن و http://127.0.0.1:4174/ را باز کن.
برای دیدن پاسخ هر فاز، سرور را متوقف کن و مثلاً npm run dev -- 01 را اجرا کن.
هر دو از یک پورت استفاده می‌کنند؛ شمارهٔ فاز بخشی از URL نیست.

راه میان‌بر در صورت گیرکردن: فایل‌های کدِ پاسخ فاز قبلی را دستی اینجا کپی کن؛ GUIDE_FA.md و CHANGES.diff لازم نیست.
کپی‌کردن پاسخ کامل فاز بعد جای تمرین را می‌گیرد؛ ابتدا خودت به ترتیب راهنما بنویس و بعد مقایسه کن.
هنگام تغییر نام .jsx به .tsx در فاز ۹، نسخه‌های قدیمی همنام را نگه ندار.
اگر پس از ویرایش، فایل‌های جدید یا tsconfig اضافه کردی و نمایش درست نشد، سرور را یک بار دوباره اجرا کن.
