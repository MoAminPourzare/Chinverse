# فاز ۹ — رفتار آماده را با قرارداد نوع دقیق‌تر کن

این بار خروجی کاربر باید دقیقاً مثل فاز ۸ بماند. هدف، کمک به برنامه‌نویس هنگام توسعه است.
در پروژه‌های کاری می‌توان از ابتدا TypeScript انتخاب کرد؛ اینجا آن را دیرتر می‌آوریم تا اثرش را جدا ببینی.

## ترتیب نوشتن

1. src/types.ts را بساز و قرارداد Book را بنویس؛ این تعریف هیچ کتاب واقعی ایجاد نمی‌کند.
2. books.js را به books.ts تغییر نام بده، نوع Book را import کن و آرایه را Book[] بنویس.
3. BookCard.jsx را به BookCard.tsx تغییر نام بده و BookCardProps را برای book، selected و onSelect تعریف کن.
4. App.jsx را به App.tsx تغییر نام بده؛ نوع selectedId را string | null و پارامتر handleSelect را string اعلام کن.
5. import داده را از ./books.js به ./books تغییر بده؛ نام main.jsx را هم main.tsx کن و script در index.html را به‌روز کن.
6. format-price.js را JavaScript نگه دار و JSDoc پارامتر number را اضافه کن؛ فایل JS هم قابل بررسی نوع است.
7. tsconfig.json را از نمونه بردار و تنظیمات strict، noEmit، allowJs، checkJs و include را بخوان.
8. فایل‌های قدیمی .jsx و books.js را پس از تغییر نام در practice باقی نگذار؛ دو نسخهٔ همنام، انتخاب import را مبهم می‌کند.

## اجرا و بررسی

پاسخ آماده: npm run dev -- 09. بررسی مستقل: npm run check -- 09.
آزمایش خطای موقت: npm run check -- 09 --demo-error. خروج ناموفق این دستور عمدی است.
در آن آزمایش قیمت در حافظه رشته می‌شود و TypeScript خطا می‌دهد؛ فایل واقعی تغییر نمی‌کند.
در practice خودت بعد از تغییرها npm run check -- practice را اجرا کن.

## چه چیزی تغییر نکرد؟

انتخاب، جست‌وجو، داده‌های کتاب و DOM مورد انتظار ثابت‌اند. interfaceها و annotationها در کد اجرایی باقی نمی‌مانند.
TypeScript پاسخ API را خودکار اعتبارسنجی نمی‌کند. این مثال هنوز API و ذخیرهٔ دائمی ندارد.
noEmit مربوط به بررسی نوع است؛ Vite همچنان تبدیل لازم برای اجرای مرورگر را انجام می‌دهد.
مسیرهای typeRoots و paths فقط به بسته‌های نصب‌شدهٔ frontend در همین مخزن اشاره می‌کنند.

## تمرین و معیار پایان

description?: string را به Book اضافه کن، در یک کتاب مقدار بده و با شرط JSX در کارت نمایش بده.
توضیح بده چرا اضافه‌کردن نوع به‌تنهایی عنصر جدیدی روی صفحه نمی‌سازد.
قدم بعد: ابزار مشاهدهٔ سورس، JavaScript تبدیل‌شده و DOM را اضافه می‌کنیم؛ منطق اصلی فروشگاه آماده است.
