# فاز ۴ — فقط روش توصیف رابط را عوض کن

هدف: بفهمی HTML اولیه، JSX، React و React DOM کجا به هم وصل می‌شوند.
خروجی این فاز یک کارت ثابت است. دکمه در این فاز و دو فاز بعد عمداً هنوز رفتار انتخاب ندارد.
رفتار DOM مستقیم فاز ۳ یک مقایسه بود؛ در نسخهٔ React آن را در فاز ۷ با state می‌سازیم.

## ترتیب نوشتن، از دید برنامه‌نویس

1. در practice فایل src/App.jsx را بساز. تابع App باید JSX همان یک کارت را برگرداند.
2. تگ‌های HTML قبلی را به JSX منتقل کن: class به className تبدیل می‌شود و JSX یک ریشه دارد.
3. src/main.jsx را بنویس: App و CSS را وارد کن، گرهٔ root را پیدا کن و با createRoot رابط را به آن متصل کن.
4. index.html را ساده کن: به‌جای کارت داخل body فقط div با id="root" بگذار و script را به src/main.jsx وصل کن.
5. فایل src/main.js فاز ۳ دیگر ورودی نیست؛ بعد از انتقال آن را از practice حذف کن تا دو روش مخلوط نشوند.
6. styles.css را از فاز ۲ نگه دار؛ ظاهر به خاطر تغییر ابزار رابط نیاز به بازنویسی ندارد.

ترتیب اجرا با ترتیب نوشتن فرق دارد: مرورگر index.html را می‌گیرد → main.jsx اجرا می‌شود → App نمایش داده می‌شود.
لازم نیست همیشه اولین فایل اجراشونده را اول بنویسی؛ اینجا اول خودِ قطعهٔ نمایشی را ساختیم.

## معنای کد تازه

App یک تابع کامپوننت است. JSX توصیف رابط را می‌سازد؛ یک رشتهٔ HTML یا خودِ DOM نیست.
Vite JSX را به JavaScript تبدیل می‌کند. React DOM مدیریت محتوای root را بر عهده می‌گیرد.
فعلاً هیچ TypeScriptی در کد برنامه نداریم: پسوند jsx یعنی JavaScript همراه JSX.

## اجرا و تمرین

پاسخ آماده: npm run dev -- 04. تغییر عنوان را این بار در App.jsx انجام بده، نه داخل index.html.
تمرین: یک توضیح به کارت اضافه کن. سپس index.html را ببین؛ توضیح کارت داخل آن نوشته نشده است.
ریشهٔ root را موقتاً اشتباه نام‌گذاری کن و خطای main.jsx را ببین؛ بعد نام را برگردان.
