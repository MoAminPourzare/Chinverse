# فاز ۱ — ابتدا چیزی برای نمایش بساز

هدف: یک کارت کتاب واقعی در مرورگر ببینیم، حتی وقتی هیچ CSS یا JavaScript نداریم.
قبل از کدنویسی نیاز را با یک جمله بنویس: «عنوان، موضوع، قیمت و یک دکمهٔ کتاب را نشان بده.»

## چه چیزی از قبل داریم؟

فقط ابزار اجرای آمادهٔ پوشهٔ مادر. فایل‌های برنامهٔ تو در practice قرار می‌گیرند.
ابزارها را در این مرحله بازنویسی نمی‌کنیم؛ مثل استفاده از ترمینال، فعلاً مصرف‌کنندهٔ آن‌ها هستیم.

## ترتیب نوشتن در practice

1. فایل index.html را باز کن. ساختار اولیهٔ html، head و body را نگه دار.
2. زبان fa و جهت rtl را مشخص کن؛ charset برای متن فارسی و viewport برای عرض موبایل است.
3. داخل body یک main و عنوان اصلی h1 بنویس.
4. داخل article یک موضوع، عنوان h2 و قیمت کتاب اضافه کن.
5. در پایان کارت یک button با type="button" بنویس.
6. کلاس‌های نمونه فقط نام‌گذاری‌اند؛ تا وقتی CSS نداریم ظاهر خاصی ایجاد نمی‌کنند.

نمونهٔ کامل همین کار، فایل index.html در همین فاز است. تنها فایل لازم این مرحله همین است.

## اجرا و نتیجه

از پوشهٔ مادر: npm run dev -- practice. برای دیدن پاسخ آماده: npm run dev -- 01.
اگر سرور دیگری از همین درس باز است ابتدا Ctrl+C بزن. آدرس هر دو حالت http://127.0.0.1:4174/ است.
عنوان، یک کارت و دکمه را می‌بینی؛ ظاهر ساده است و کلیک دکمه هنوز هیچ رفتاری ندارد.

## این مرحله چه چیزی یاد می‌دهد؟

مرورگر از HTML ساختار سند را می‌سازد. هنوز React، JSX، state یا TypeScript وارد کد برنامه نشده‌اند.
از همین ابتدا نیازی به ساخت ده فایل نداریم؛ ابتدا کوچک‌ترین خروجی قابل مشاهده را می‌سازیم.

## تمرین و معیار پایان

عنوان کتاب را تغییر بده و صفحه را ببین. یک توضیح کوتاه بعد از قیمت اضافه کن.
وقتی می‌توانی محل تغییر هر متن را پیدا کنی و می‌دانی چرا دکمه هنوز کاری نمی‌کند، فاز تمام است.
از خودت بپرس: آیا نوشتن button به‌تنهایی یعنی قابلیت انتخاب را پیاده کرده‌ام؟ پاسخ: خیر، فعلاً فقط عنصر داریم.

قدم بعد: همین صفحه را در فاز ۲ ظاهر می‌دهیم؛ قرار نیست HTML را از نو طراحی کنیم.
