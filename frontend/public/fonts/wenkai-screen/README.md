LXGW WenKai GB Screen, distributed by lxgw-wenkai-screen-webfont 1.7.0.

Typeface source: https://github.com/lxgw/LxgwWenKai-Screen

Font license: SIL Open Font License 1.1 (OFL.txt).
Webfont packaging license: MIT (WEBFONT-LICENSE.txt).
Unmodified WOFF2 subsets are self-hosted. Only CJK Unicode ranges are declared;
Persian and pinyin keep their existing fonts. Shards load only when required.
The Screen face uses the author's screen-adjusted medium drawing. CSS maps
weights 400–900 to this face and disables synthetic bold for Chinese text.
The GB variant follows mainland Chinese glyph conventions for Mandarin lessons
and also covers the traditional characters currently used by the application.

Reproduce: extract the pinned npm tarball and run
node frontend/scripts/prepare-ui-theme-assets.mjs path/to/extracted/package
