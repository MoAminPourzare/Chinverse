# پایان اصلاح کاتالوگ‌ها از روی تصاویر مرجع

تاریخ: ۲۰۲۶-۰۹-۲۶؛ شاخهٔ تحویل: `codex/phase-8-beta-release`.

صفحه‌های کاوش، جزئیات و درس با تصاویر فرستاده‌شده تکمیل شدند. این مرحله شامل
HSK، تلفظ، نویسه‌ها، گرامر، اصطلاحات، چینی کاربردی، ولاگ، مترادف‌ها، چینی کلاسیک،
سریال، فیلم، انیمیشن، موسیقی، پادکست، گفت‌وگوهای موضوعی، آشپزی، هنرهای رزمی،
انرژی و سلامت، خوشنویسی، فرهنگ چای، متون فرهنگی، داستان‌های تاریخی، شعر کلاسیک
و آیین‌ها و جشن‌ها است.

عنوان‌ها، ترتیب، تعداد قسمت‌ها، گروه‌بندی‌ها و کاورها از مرجع ثبت شدند. تکرارهای
واقعی عنوان و شماره حفظ شده‌اند: برای نمونه، سه‌حرفی ۶۳ ردیف با شماره‌های ۱ تا ۶۲
و دو قسمت ۳۴ دارد؛ مجموعهٔ چای ۵۸ بخش در ۴۳ فصل چاپ‌شده دارد. شعر کلاسیک ۶۵
قسمت، داستان‌های Xiao Lin هجده قسمت و جشن‌های سنتی ده قسمت دارند. تصویر تکراری
از یک ردیف هنگام اسکرول، قسمت اضافه ایجاد نمی‌کند.

## رفتار انتشار و پخش

- کارت مرجع فقط به دورهٔ منتشرشده با هویت مشخص همان مجموعه متصل می‌شود.
- قسمت فقط با رسانهٔ ثبت‌شده و شمارهٔ صریح و یکتای آن آمادهٔ پخش می‌شود؛ عنوان
  مشابه یا ترتیب اتفاقی پاسخ API برای انتخاب ویدیو کافی نیست.
- شماره‌ها یا شناسه‌های جایگزین متناقض در قسمت، سطح پادکست، سطح خوشنویسی یا
  انتشار موسیقی پذیرفته نمی‌شوند.
- قسمت‌های فاقد فایل اصلی، وضعیت «هنوز منتشر نشده» دارند. مدت، پیشرفت و امتیاز
  واقعی برای آن‌ها ساخته نشده است.
- شناسه‌های عددی دوره‌های API همچنان مسیر جزئیات خود را دارند و ذخیره‌سازی
  منتخب‌ها با شناسهٔ واقعی دورهٔ منتشرشده انجام می‌شود.

## اعتبارسنجی پیش از تحویل

- ۲۲۳ تست واحد فرانت‌اند در ۵۸ فایل با پوشش خطوط ۹۵٫۳۵٪؛ lint و TypeScript.
- بیلد production و محدودیت حجم فایل‌های عمومی، JavaScript و پلیر HLS.
- مجموعهٔ کامل مرورگر: ۱۷۱ موفق، ۸ skip مطابق پیش‌شرط محیط؛ شامل Chromium
  دسکتاپ و موبایل، WebKit موبایل، دسترس‌پذیری، تغییر جهت، بزرگ‌نمایی و PWA.
- تست‌های بک‌اند بدون دیتابیس integration: ۱۹۱ موفق با پوشش ۶۰٫۱۹٪؛ ruff،
  بررسی امنیتی Bandit و سلامت وابستگی‌ها نیز موفق بودند.
- npm audit وابستگی‌های production: بدون آسیب‌پذیری گزارش‌شده.
- بررسی baseline انتشار، gate محلی مرحلهٔ ۸ و تطابق ساختاری registry رسانه موفق
  بودند. بررسی integration دیتابیس و انتشار staging توسط CI همان کامیت انجام می‌شوند.
- تست پایدار اتصال قسمت‌های منتشرشده برای داستان، شعر، جشن، چای و سه‌حرفی
  افزوده شد؛ شمارهٔ متناقض، عنوان بدون شماره و قسمت بدون رسانه نیز آزموده می‌شوند.

## حدود تحویل

این مرحله آماده‌سازی و تحویل کاتالوگ و رابط است. فایل‌های ویدیوی واقعی که ارائه
یا منتشر نشده‌اند، با تصویر مرجع جایگزین نمی‌شوند. بررسی مجوزهای رسانه برای
انتشار عمومی و شواهد provider طبق runbook انتشار همچنان فرایند مستقل خود را دارند.
این گزارش تأیید لانچ عمومی نیست.

تصاویر اصلی صاحب پروژه در پوشهٔ `پروفایل دوره ها` حفظ شده‌اند؛ نسخه‌های runtime
در `frontend/public/assets` و registry موجود هستند. پوشهٔ اصلی در Git نادیده گرفته
می‌شود تا نسخه‌های تکراری و غیرمصرفی وارد تحویل نشوند.

دستور جدید صاحب پروژه در این تاریخ، کامیت و تکمیل تحویل را مجاز کرد. یادداشت‌های
قدیمی «بدون کامیت/پوش» در دفتر جلسات، فقط وضعیت تاریخی همان جلسه‌اند.
